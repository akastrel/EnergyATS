# Проверки Energy ATS 0.3.0

Команда:

```bash
pytest -q
```

Текущий результат: **67 passed**.

## Generator Controller

Проверены:

- полный запуск с заслонкой, RUNNING, прогревом и `ready_for_load`;
- стратегия по `ambient_temperature_external`;
- консервативный холодный запуск при неизвестной температуре;
- внешний запуск без единой управляющей команды;
- внешнее включение REMOTE до появления RUNNING;
- восстановление ownership только для сохранённой устойчивой сессии;
- отмена запуска с подтверждением снятого REMOTE;
- запрет остановки двигателя под нагрузкой;
- cooldown до снятия REMOTE;
- сохранение активной фазы при кратковременном `unknown/unavailable`;
- безопасные команды REMOTE OFF и заслонка RUN после timeout запуска;
- точная граничная семантика температурного порога.

## Power Transfer

Проверены:

- запрет ввода генератора до `ready_for_load`;
- break-before-make при переходе Grid → Generator;
- подтверждаемый возврат Generator → Grid;
- возврат Generator → BATTERY при отсутствующей Grid;
- timeout силового шага с переходом в recovery;
- наблюдение внешнего изменения топологии без команды;
- запрет одновременных несовместимых положений Grid/Generator;
- проверка конкретного работающего агрегата перед подтверждением ввода;
- сохранение незавершённой фазы при кратковременной потере датчика.

## Energy Supervisor

Проверены:

- ручная сессия при доступной Grid не отменяется самим фактом наличия сети;
- ручная outage-сессия возвращает дом на Grid и оставляет двигатель работать;
- ручная остановка без Grid переводит дом на аккумуляторы МАП без ложного
  warning;
- после ручной остановки без Grid АВР не запускает генератор
  повторно до возврата Grid или новой ручной команды запуска;
- внешний запуск только уведомляется и блокирует управляющие действия;
- отказ генератора изолируется без автоматического запуска второго;
- потеря связи требует recovery только при незавершённой транзакции;
- продолжительный ручной холостой ход создаёт предупреждение, но не остановку;
- локальная остановка уже разгруженного ручного генератора завершает сессию
  без команд и без ложной аварии;
- повторный провал Grid во время автоматического cooldown возвращает ещё
  работающий генератор в работу;
- внешний сеанс не захватывается даже после остановки двигателя с оставленным
  генераторным положением силовой схемы;
- второй активный агрегат во время управляемой сессии изолируется без fallback;
- команды не откладываются до неожиданного выполнения после восстановления
  отсутствовавших данных;
- отключение и повторное включение АВР начинает выдержку Grid заново;
- неизвестная версия журнала и несовпадение сохранённого источника с физическим
  состоянием требуют recovery.

## App и HA Adapter

Проверены:

- компактная конфигурация без generator-specific параметров;
- чтение внешней температуры только адаптером Python;
- новые однозначные entity заслонки;
- отсутствие аппаратных service calls в DISARMED;
- приоритет изоляции шины перед остановкой двигателя;
- независимые проверки физических предусловий непосредственно перед HA-командой;
- атомарная запись pending-команды до первого аппаратного call;
- восстановление устойчивой управляемой сессии без повторных service calls;
- pending-команда и неизвестная версия общего журнала восстанавливаются только
  в `RECOVERY_REQUIRED`;
- сквозной ручной сценарий:
  `choke → REMOTE → RUNNING → warmup → transfer → return → cooldown → stop`;
- реальный WebSocket roundtrip тестового HA-сервера.
