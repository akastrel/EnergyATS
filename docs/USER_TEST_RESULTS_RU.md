## M2. Полный ручной цикл PRIMARY

**Результат:** PASS с некритичными замечаниями.

Фактическая последовательность:

- в 13:12:46 пользователь запросил резервное питание;
- Elemax запустился с управлением заслонкой, подтвердил RUNNING и завершил прогрев;
- перед transfer обе управляемые группы G1/G2 отключились;
- Grid path был подтверждённо разомкнут, затем дом перешёл через `UPS_ONLY` на Elemax;
- после команды возврата generator path был разомкнут, дом перешёл через `UPS_ONLY` на Grid;
- G1/G2 восстановились;
- после cooldown Elemax штатно остановился в 13:17:27.

Ожидаемый порядок `generator start -> warmup -> Generator supply -> Grid return -> cooldown -> generator stop` выполнен. Break-before-make и работа G1/G2 фактически подтверждены.

Некритичные замечания:

- App log не содержал сообщения о командах Generator Controller, Power Transfer и Load Manager, хотя должен быть полным диагностическим журналом;
- формулировки сообщений о запуске и остановке генератора звучали неестественно;
- отдельная привязка DETAIL-записей к `sensor.energy_ats_activity_detail` оказалась не нужна: подробная картина должна находиться в App log, а основной HA Logbook должен оставаться кратким.

Замечания исправляются в версии 1.0.6 в том же PR, где начат этот журнал результатов.
