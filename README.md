# EnergyATS

`EnergyATS` — контроллер автоматического ввода резерва для двух генераторов,
Home Assistant и AppDaemon.

Проект разделён на два слоя:

- `ats_core.py` — чистый конечный автомат без зависимости от Home Assistant;
- `energy_ats.py` — адаптер AppDaemon, который читает реальные сущности HA и
  исполняет действия конечного автомата;
- `energy_ats.yaml` — настройки приложения и временные параметры АВР.

## Принципы безопасности

- Физическая обратная связь — единственный источник истины. Состояния helper-ов
  Home Assistant не используются как подтверждение положения контакторов или
  работы генераторов.
- Силовое переключение выполняется поэтапно с ожиданием физического
  подтверждения каждого шага.
- После перезапуска AppDaemon состояние восстанавливается по фактическим
  датчикам, а не по сохранённой фазе алгоритма.
- При неопределённой критической ошибке контроллер переходит в `TERMINAL`,
  снимает команды запуска, возвращает обычные органы управления в положение
  Grid и включает общий `Emergency Stop`.
- Если первый генератор не запускается или останавливается, выполняется одна
  попытка запуска второго. Бесконечного переключения A ↔ B нет.

## Первый запуск

1. Поместить `ats_core.py` и `energy_ats.py` в каталог приложений AppDaemon.
2. Добавить блок из `energy_ats.yaml` в конфигурацию приложений AppDaemon либо
   подключить файл согласно текущей структуре конфигурации.
3. Проверить соответствие всех `entity_id` реальным сущностям Home Assistant.
4. Оставить `armed: false` и убедиться по журналу AppDaemon, что все обязательные
   сущности доступны.
5. Отдельно проверить датчики Grid/Generator, обратную связь силовых реле,
   `REMOTE START`, заслонки и `Emergency Stop`.
6. Только после проверки сценариев изменить `armed` на `true`.

`armed: false` — обязательное состояние для первого запуска. В этом режиме
приложение загружается и проверяет конфигурацию, но не управляет оборудованием.

## Основные сценарии

- автоматический запуск при устойчивом исчезновении основной сети;
- ручной ввод резерва через кнопку Home Assistant;
- температурно-зависимый прогрев и управление воздушной заслонкой;
- подтверждаемый перевод дома с Grid на Generator;
- автоматический возврат после выдержки стабильности сети;
- ручной возврат на Grid для ручной резервной сессии;
- работа генератора без нагрузки перед остановкой;
- резервирование генераторов A и B;
- безопасное восстановление после перезапуска AppDaemon;
- терминальная блокировка при критической неопределённости.

## Проверка Python-файлов

Перед развёртыванием можно проверить синтаксис без запуска Home Assistant:

```bash
python3 -m py_compile ats_core.py energy_ats.py
```

## Важно про заслонки

Текущие имена кнопок ESPHome обратны фактическому механическому движению:

- `button.generator_*_choke_open` физически закрывает заслонку для холодного
  старта;
- `button.generator_*_choke_close` физически открывает заслонку в положение
  `RUN`.

Это явно учтено в `ats_core.py` и подробно прокомментировано в коде.
